# Contractors Supply Website Concept

Static HTML/CSS/JS website adapted from the M Shelton project and refined for a building-materials supplier.

## Local preview
Open `index.html` in a browser or serve the folder with any static HTTP server.

## Quote form
The quote form submits through Formspree using the configured demo endpoint. Confirm the target email and form settings before handing the site to the business.

## Demo-to-production checklist
- Replace concept artwork with approved company photography.
- Confirm product catalog and exact departments.
- Confirm hours, delivery area/terms, and contact information.
- Confirm Formspree target email.
- Add analytics/SEO details and privacy notice before launch if needed.
